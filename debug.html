Shader compile diagnostics

The link wait includes backend shader compilation/optimization, not just linking. GPU rendering throughput does not predict this CPU-side cost. Tests run one program at a time, on demand.

A different comment or unused #define is not a reliable cold-cache test: it can vanish before the native cache lookup. The live-literal probe changes a used output multiplier, but even that cannot guarantee a driver-cache miss. For controlled cold runs use a fresh browser process/profile with shader disk caching disabled; see the measurement guide.

idle

Component comparisons replace one function with a stub (diagnosis only, not equivalent images). Saved reports include the exact GLSL, source hashes, timings, browser/backend identity, and optional translated source. First-use timing catches backends that defer native compilation until drawing; its one-pixel result is not rendering performance.
